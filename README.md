# Intervalos

Temporizador de intervalos para entrenar. Configurás segundos de **trabajo**, **descanso**, cantidad de **series** y, si querés, **bloques** con una **pausa larga** entre ellos. Avisa con sonido, voz o vibración en cada cambio.

- **Mis rutinas**: guardá combinaciones con nombre y arrancalas con un toque. Se guardan en el navegador de cada celular.
- **Avisos**: Sonido, Solo vibración (solo Android) o Silencio. Se cambia también durante el entrenamiento con el botón de arriba.
- **Voz**: dice "descanso", "¡dale!", "pausa larga", "último bloque", "última serie".
- Funciona sin internet una vez instalada.

## Publicarla gratis con GitHub Pages

1. El repositorio tiene que ser **público**: *Settings → General → Danger Zone → Change visibility → Public*.
2. *Settings → Pages → Build and deployment → Source: Deploy from a branch*.
3. Elegí la rama donde está `index.html` y la carpeta `/ (root)`, y tocá **Save**.
4. En uno o dos minutos queda en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.

## Instalarla en el celular

- **Android (Chrome)**: abrí el link → menú ⋮ → **Agregar a pantalla de inicio** / **Instalar app**.
- **iPhone (Safari)**: abrí el link → botón Compartir → **Agregar a inicio**.

Se abre a pantalla completa, como una app, y mantiene la pantalla prendida mientras corre.
